This is IZOS-NSPIRE - A linux distribution for the TI nSpire calculators.
<br><br>
<i>NOTE:While this is called <b>IZOS</b>-nspire, It's not an complete IZOS port, but rather an IZOS-inspired project.</i>

## Features
- Custom app selection
- Unique UI
- BusyBox userspace
- Built using busybox

## File structure
The project file strcture is quite simple.
```
/
├─ buildroot/ -- Buildroot files
├─ apps/ -- Sources for apps that aren't in Buildroot.
├─ scripts/ -- Scripts for building, patching...
├─ kernel/ -- Contains the kernel
```
